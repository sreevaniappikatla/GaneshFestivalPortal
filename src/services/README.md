# services

This folder will hold data-access/service modules (e.g. Supabase queries,
API clients) that pages and components call into.

Intentionally empty during initial project setup — no backend integration
has been added yet. Future services might include:

- `scheduleService.ts` — fetch/create festival schedule events
- `registrationService.ts` — submit and list pooja registrations
- `announcementService.ts` — fetch/post announcements
- `authService.ts` — admin authentication
